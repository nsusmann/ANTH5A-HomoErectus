# ANTH5A Homo erectus discovery map

Interactive classroom map showing when Homo erectus fossil localities became known, with display modes ordered by discovery date and by fossil age. Includes a selector for inclusive Homo erectus versus a debated split model that highlights Koobi Fora as a potential Homo ergaster locality, plus color coding by discovery year or fossil-age range midpoint. Numbered map points remain tied to the locality list. The page also includes downloadable SVG map exports.
